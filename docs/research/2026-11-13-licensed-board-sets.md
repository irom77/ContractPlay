# Redistribution options for bridge board sets

Reviewed November 13, 2026. This is a source and license check for the open TODO item about adding curated, distributable board sets. It is not legal advice.

## Findings

- The public [`ContractBridge/pbn-files` repository](https://github.com/ContractBridge/pbn-files) describes itself as a collection of PBN files found on the web. Its repository page does not state a license for the hand records. Public availability and a PBN format do not establish permission to copy or redistribute those records, so it is not a cleared source.
- The [Practice Bidding Scenarios repository](https://github.com/bridge-craftwork/Practice-Bidding-Scenarios) describes its content as being shared broadly and says the author does not want to pursue copyright. This is useful evidence of the author's intent, but the repository does not state a standard license or explicit grant allowing commercial redistribution and modification. Do not treat the repository text alone as a clear license for bundling its deal files.
- [PBBridge's TrueDeal page](https://pbbridge.com/) describes a dealing program that creates sets of bridge deals. Its linked freeware license allows use of the **program** for non-commercial purposes; the site does not state that deal files generated by the program are licensed or that they may be redistributed commercially. It is not a safe bundled-data source for ContractPlay.
- A clean alternative is for ContractPlay to generate its own sets with its existing random deal generator, persist a reproducible generated set, and optionally compute double-dummy par using the already integrated Apache-licensed DDS. That would be newly generated deal data, not a redistributed archive. A curated pedagogical set and recorded auction/play would still need original authored content or explicit permission.

## Recommendation

Do not bundle an external archive based only on a public download, a permissive-sounding repository description, or the license of the program that generated it. Close the licensing item only after obtaining an explicit grant covering the intended redistribution and use, or by scoping the feature to ContractPlay-generated deal sets and documenting that decision. If asking a rights holder, request permission to host and redistribute the PBN deals and any score tables, analyses, auctions, or play records, including for commercial use and modification if those are intended.

## Primary sources checked

- [`ContractBridge/pbn-files` repository](https://github.com/ContractBridge/pbn-files) (collection description; no repository license statement observed on the public repository page).
- [`Practice-Bidding-Scenarios` repository](https://github.com/bridge-craftwork/Practice-Bidding-Scenarios) (author describes broad-sharing intent but no explicit standard license was observed).
- [PBBridge](https://pbbridge.com/) (describes TrueDeal's generated deal sets and links its non-commercial freeware license for programs).
- [Apache License 2.0](https://www.apache.org/licenses/LICENSE-2.0) (license for the DDS dependency already used for double-dummy analysis; it does not grant rights in third-party deal archives).
